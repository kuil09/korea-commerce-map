# 대한민국 커머스 지도 - 확장 Context (Full Context)

> 이 파일은 LLM이 전체 데이터 구조를 한 번에 로드할 수 있도록 설계되었습니다.

## Site Structure (사이트 구조)

```
korea-commerce-map/
├── index.html        # 메인 페이지 (웹 UI)
├── index.md          # 메인 페이지 (LLM용 Markdown 버전)
├── llms.txt          # LLM용 사이트 설명서
├── llms-ctx-full.txt # LLM용 전체 데이터 포함 확장 context
├── data/
│   ├── categories.json  # 카테고리 정의
│   ├── platforms.json   # 플랫폼 데이터 (JSON)
│   └── platforms.yaml   # 플랫폼 데이터 (YAML)
├── scripts/
│   └── generate-llms.js # llms.txt 및 llms-ctx-full.txt 생성 스크립트
└── templates/
    ├── llms.txt.template           # llms.txt 템플릿
    └── llms-ctx-full.txt.template  # llms-ctx-full.txt 템플릿
```

## Data Schema (데이터 스키마)

### Category Schema

```json
{
  "id": "string (unique identifier)",
  "name": "string (Korean name)",
  "nameEn": "string (English name)",
  "icon": "string (emoji icon)"
}
```

### Platform Schema

```json
{
  "id": "string (unique identifier)",
  "name": "string (Korean name)",
  "nameEn": "string (English name)",
  "description": "string (service description)",
  "url": "string (main page URL)",
  "categories": "string[] (category IDs)",
  "deliveryMethods": "string[] (delivery method names)",
  "deliveryTime": "string (delivery time description)",
  "minOrderAmount": "string (minimum order amount)",
  "features": "string[] (key features)",
  "status": "active | rebranded | suspended | closed | unverified",
  "verificationStatus": "verified | partial | unverified",
  "lastVerifiedAt": "ISO date or null",
  "verifiedFields": "string[] (fields checked against sources)",
  "sourceUrls": "string[] (HTTPS evidence URLs)"
}
```

Records without explicit verification metadata are normalized to `unverified`.
`lastVerifiedAt` applies only to the fields listed in `verifiedFields`.

## Usage Notes for LLMs (LLM 사용 안내)

### 자주 수행되는 작업

1. **카테고리별 서비스 그룹핑**: `platforms.json`의 각 서비스에서 `categories` 배열을 기준으로 그룹화
2. **배송 속도 비교**: `deliveryTime` 필드를 파싱하여 비교 (예: "30분~1시간" < "당일" < "익일" < "2~3일")
3. **최소 주문 금액 비교**: `minOrderAmount` 필드 파싱 ("없음" = 0, 숫자 추출)
4. **배송 방식 필터링**: `deliveryMethods` 배열에서 특정 배송 방식 포함 여부 확인
5. **특징 기반 검색**: `features` 배열에서 키워드 매칭

### 배송 속도 정규화 가이드

| 패턴 | 의미 | 예상 시간(시간) |
|---|---|---|
| "30분~1시간" | 즉시배송 | 0.5-1 |
| "3시간" | 오늘드림 | 3 |
| "당일" | 당일배송 | 12 |
| "익일", "새벽" | 다음날 도착 | 24 |
| "1~3일" | 일반배송 | 24-72 |
| "2~5일" | 오픈마켓 | 48-120 |
| "2~7일" | 가전/가구 | 48-168 |
| "판매자별 상이", "상품별 상이" | 가변적 | - |
